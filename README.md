# HTML to DOCX API

**Тема курсовой работы:** «Веб-приложение с HTTP API для асинхронного преобразования файлов из формата HTML в формат Docx».

**Практическая работа № 2, вариант № 1.**

## Описание проекта

Проект предназначен для преобразования файлов HTML в документы DOCX.

На первом этапе реализована CLI-утилита на Python, принимающая путь к исходному HTML-файлу и путь для сохранения DOCX-файла.

## Этапы работы

1. CLI-утилита для преобразования HTML в DOCX.
2. HTTP API на Bottle, клиент API и модельное тестирование с Hypothesis.
3. Хранение данных в SQLite с использованием PonyORM.

## Реализованные возможности первого этапа

- Чтение HTML-файлов в кодировке UTF-8.
- Создание DOCX-документов.
- Преобразование заголовков `h1`–`h6`.
- Преобразование обычных абзацев.
- Преобразование маркированных и нумерованных списков.
- Сохранение жирного, курсивного и подчёркнутого текста.
- Сохранение результата по указанному пути.

## Функции и классы

### `HTMLToDOCXParser`

Класс для обработки HTML-документа.

- `__init__()` — инициализирует парсер.
- `handle_starttag()` — обрабатывает открывающие HTML-теги.
- `handle_endtag()` — обрабатывает закрывающие HTML-теги.
- `handle_data()` — переносит текст с форматированием.
- `start_paragraph()` — создаёт абзац с соответствующим стилем.

### `convert_html_to_docx(input_path, output_path)`

Читает HTML-файл, преобразует его содержимое и сохраняет DOCX-документ.

### `main()`

Обрабатывает аргументы командной строки и запускает преобразование.

## Требования

- Python 3.11.
- Библиотеки из `requirements.txt`.

## Установка зависимостей

Создать виртуальное окружение:

```powershell
py -3.11 -m venv .venv
```

Активировать его в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

Запуск CLI-утилиты:

```powershell
python -m src.cli example1.html example1.docx
```

Запуск через `run.bat`:

```powershell
.\run.bat example1.html example1.docx
```

Первый аргумент — путь к исходному HTML-файлу.

Второй аргумент — путь к создаваемому DOCX-файлу.

## Примеры использования

Для проверки первого этапа подготовлены пять HTML-файлов:

1. `example1.html` — заголовок и обычные абзацы.
2. `example2.html` — несколько уровней заголовков.
3. `example3.html` — маркированный и нумерованный списки.
4. `example4.html` — жирный, курсивный и подчёркнутый текст.
5. `example5.html` — комбинированный HTML-документ.

Пример запуска:

```powershell
python -m src.cli example5.html example5.docx
```
